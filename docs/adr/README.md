# Architecture Decision Records (ADRs)

English | [Deutsch](README.de.md)

Short records of the base decisions that shape the engine. One file per
decision, numbered `NNNN-title.md` (with a `NNNN-title.de.md` German twin).
An ADR states the context, the decision, and its consequences — it is the
durable "why", alongside the "how" in the [architecture paper](../architecture.md).
