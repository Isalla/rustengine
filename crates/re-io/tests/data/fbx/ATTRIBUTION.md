# FBX test fixtures

All `.fbx` files in this directory are copies from the
[ufbx](https://github.com/ufbx/ufbx) regression corpus (`data/`):

- `blender_272_cube_7400_binary.fbx`
- `blender_293_half_skinned_7400_binary.fbx`
- `maya_transform_animation_7500_binary.fbx`
- `maya_advanced_skinned_pivot_7700_binary.fbx`
- `max_transformed_skin_6100_binary.fbx` (rejection test: version < 7.4)
